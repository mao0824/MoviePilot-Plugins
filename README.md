# NAS 哨兵 (NasSentinel) — MoviePilot 插件

一个**通用巡检哨兵**插件:把「站点签到、考核进度、刷流与磁盘 IO 健康」这三件需要人盯的事，变成自动巡检 + 到点告警。

## 特性

- 🔐 **通用 NexusPHP 签到补位**——为 AutoSignIn 未覆盖的站点补位；自动识别「表单式 / 链接式」签到并幂等执行，不重复提交
- 📊 **考核进度追踪**——解析 NexusPHP 标准考核公告，跟踪「上传增量 / 做种积分」等指标，并**按实测速率外推**预计达成时间与风险等级
- 🩺 **IO / 刷流健康哨兵**——采样系统负载与物理磁盘队列、读写速率，并在**上传速率异常**时告警（专门定位「上传被下载随机 IO 掐死」这类隐形故障）
- 🔔 **每日简报 + 异常即报**——复用 MoviePilot 已有通知渠道（Telegram / 邮件等），异常侧带冷却避免刷屏
- ⚙️ **自动降级（默认关闭）**——连续超红线时自动下调刷流下载并发，带冷却，可在配置页开启
- 🧩 **零硬编码**——设备名、下载器名、站点、阈值全部可配置，不绑定任何特定 NAS

## 安装

1. MoviePilot → 设置 → 插件 → 添加插件仓库，填入本仓库地址
2. 安装并启用「NAS 哨兵」
3. 在插件配置页选择站点、填写阈值后即可

## 说明

- 签到与考核解析使用 **Cookie**（读取 MoviePilot 中已配置的站点凭据），插件本身不额外存储明文
- IO 采样读取 `/proc/loadavg` 与 `/proc/diskstats`，需容器可见宿主机 `/proc`（默认即可）
- 日志中未识别签到方式时会输出探测结果，便于人工确认站点机制
