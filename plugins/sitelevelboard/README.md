# 站点等级看板 (SiteLevelBoard)

把 **绑定站点的等级 / 下一级条件 / 到达下一级的预计时间(ETA) / 全部等级阶梯 / 保号与封号条款**
汇成一页看板，并给出**流量时间线**（上传、下载、分享率、魔力、做种 的历史曲线）。

## 特性

- 📋 **站点一览**——每站的当前等级、下一级、**最紧条件**（卡住晋级的那一项）、ETA 与可信度、红线状态
- ⭐ **下一等级还缺什么**——逐条列出「已达成 ✅ / 未达成 ❌ + 当前值 / 目标值 + 增速 → 预计天数」
- 🪜 **全部等级阶梯**——每级条件与特权，标注 🏅 永久保号档
- 🛡️ **保号与封号条款（站点原文）**——并给出「**离可封存保号还差几级**」「**离永久保留还差几级**」
  （实测经验：**「永远保留」门槛极高，真正可执行的动作是「封存账号」**，所以这两个数字分开给）
- 📈 **流量时间线**——基于 MoviePilot 自带的 `siteuserdata` **每日快照**（不是自建采样），看得到上传/下载趋势
- 🔔 **通知三开关**——`等级变化` / `风险` / `ETA 阈值` **互相解耦、任意组合**（默认前两个开）

## 数据来源与优先级

| 层 | 来源 | 说明 |
|---|---|---|
| **当前值** | **自己取**（直读 mp 的 `user.db` → `siteuserdata`） | 该表按 `updated_day` **每天一行**，是天然的历史快照 → 斜率不必自建 |
| **等级规则** | **站点页 → 内置快照 → 手动规则** | 站点页可解析时以站点页为准（并标注来源）；否则用内置快照；都不行则只显示当前等级 |

内置等级规则快照来源:**[PT-depiler](https://github.com/pt-plugins/PT-depiler)**（MIT，342 站定义）
与站点页逐项交叉核对。快照日期显示在界面上。

内置快照覆盖:**馒头、PTS、PT时间**（已与站点页交叉核对）。未覆盖的站点自动降级为
「只显示当前等级」，可以用「手动规则」补充等级门槛。

## 界面

- **数据页**：站点一览（等宽表）→ 每站一张卡（进度条 / 下一级条件 / 保号状态 / 条款原文）→ 流量时间线 → 风险汇总
- **配置页**：① 通用（cron 默认 `45 8 * * *`，避开 08:00 与 08:30 的其它插件）② 通知（三开关）
  ③ 数据源（参与站点、优先来源、是否抓站点页）④ 规则与兜底（手动规则）

> 站点一览用等宽文本渲染（`div` + `text-pre-wrap`）——MP 数据页渲染器对 `VDataTable` 的透传尚未验证，
> 待 PoC 通过后再升级成真表格。

## 与其它插件的边界

**本插件不依赖任何其它插件**——所有数据只来自 mp 自带的 `user.db`、站点页，以及自己落盘的
插件数据；不读别的插件的库表，也不调别的插件的端点。

| 插件 | 职责 |
|---|---|
| `SiteStatistic` | 站点数据统计（只看现状） |
| `SiteAssessment` | 新手考核（有截止日期的临时任务） |
| `BrushFlow` | 刷流抓种删种（本插件**不改任何种子**） |
| **本插件** | **等级与晋级**：当前等级、下一级条件、ETA、阶梯、保号/封号风险 |

## 当前数据来源（每站一览）

| 站点 | 等级规则（阶梯） | 当前值 | 说明 |
|---|---|---|---|
| **PTS** | 内置快照（`/faq.php` 做存在性校验） | 站点页顶栏：分享率 / 魔力 / **做种积分** | 做种积分不在 `siteuserdata`，靠 `live_history` 攒斜率 |
| **PT时间** | **站点页整段重建**（`/action.php?type=vertify_class` 的「等级规则」段） | 同页：注册周 / 下载量 / 上传量 / 分享率 | 条款取自 `/rules.php`（「X 及以上」保号档按原文标注） |
| **馒头** | 内置快照（**站点不公开门槛**） | **官方 API** `POST api.m-team.cc/api/member/profile`：等级 / 分享率 / 上传下载 / 最后登录 / 是否封存 / 警告 | 需要站点 API Key（在 MoviePilot 的站点配置里填）；API 的 `seedtime` 单位不明，不展示也不参与判据 |
| **其它站** | 站点页 → 内置快照 → 手动规则 | `siteuserdata` 每日快照 | 都拿不到时只显示当前等级 |

取不到站点页/API 时**一律回落到 `siteuserdata` 与内置快照**，不会因为站点改版把看板搞崩；界面会如实标注来源（站点页 / 快照 / 仅当前等级）。

## 已知限制

- **站点页改版**：解析器按「锚点 + 正则」实现，站点改版可能解析失败 —— 此时自动回落快照并在界面标注来源（不会报错、不会显示错数据）
- **PTS 的「做种积分」**：`siteuserdata` 里没有，靠站点页取值 + `live_history` 攒斜率；**攒够 3 天样本后 ETA 才会出现**
- **馒头**门槛不公开 → 阶梯用内置快照（UI 标注「快照」），但等级与当前值走官方 API
- **Rousi** 未收录规则 → 只显示当前等级
- `下载量` 类条件归为「**需人为推动**」：不参与 ETA 推算，只提示「光等不会达成」
- **ETA 口径**：只有全部条件达成才是 0 天；存在「算不出 ETA」的条件时显示「无法估算」，不会谎报「已达成」
